# Чтение листа один раз: замер по корпусу, 15.11.2026

Замер к ветке `perf/sheet-read-once-20261115`. Измеряется флаг
`DRAWING_SHEET_READ_ONCE` (`core/drawing_processor.py::enrich_fragments`):
при `DRAWING_PDF_FULL_READ` лист разбирается целиком **до** вырезок, и
вырезки видов той страницы, где лист прочитан целиком, к модели больше не
уходят. Без флага лист, нарезанный MinerU на N видов, стоит N+1 проходов
«лист целиком».

**Итог: флаг включать не надо.** Он снимает 6.8 % времени модели и теряет
при этом размеры, шероховатости и обозначения на половине затронутых
страниц. Ниже — чем это измерено.

## Откуда брались данные

Модель заново не вызывалась. Прод сохранил **оба** чтения каждой
страницы — и лист целиком, и каждую вырезку, — поэтому сравнение идёт по
записанному: это не перечитывание, а то, что прод прочитал на самом деле,
и разброс модели между прогонами в сравнение не попадает вовсе.

Чертёжные фрагменты — из `platform_parser_ingest_queue.parser_payload`
(чтение, без записи):

```sql
\copy (
  with f as (
    select q.event_id, q.s3_fileid,
           jsonb_array_elements(d->'fragments') as fr
    from platform_parser_ingest_queue q,
         lateral jsonb_array_elements(coalesce(q.parser_payload->'documents','[]'::jsonb)) d
  )
  select event_id, s3_fileid, fr->>'fragment_id' as fragment_id,
         coalesce(fr->'provenance'->>'source_page', fr->'position'->>'page') as page,
         fr->'content'->>'image_ref' as image_ref,
         fr->'content'->>'text' as text,
         fr->'content'->'structured_drawing_fields' as fields,
         fr->'content'->'structured_payload' as payload
  from f where fr->>'type' = 'drawing'
) to stdout with csv header
```

Время — строки `Qwen-VL итог:` из журналов трёх воркеров за 36 часов
(2893 вызова `process`, у каждой строки свои секунды — `_log_sheet`).

Прогон и сводка — `tools/replay_sheet_read_once.py`.

Лист целиком узнаётся по `transcript_line_count` в `structured_payload`,
вырезка — по `image_ref`, который начинается с `assets/`.

## Что получилось

Выгрузка: 7598 чертёжных фрагментов. Страниц, где флаг действует (лист
прочитан целиком **и** есть вырезки) — **432**, вырезок на них — **1118**.

### Время — 6.8 %, а не 10 %

| | |
|---|---|
| всего вызовов модели в журнале | 2893 |
| всего времени модели | 46918 с |
| снимается флагом | **3196 с = 6.8 %** |
| вырезок из снимаемых нашлось в журнале | 256 из 1118 |

Выгрузка — вся очередь, журнал — 36 часов, поэтому в журнале есть лишь
часть вырезок. 6.8 % — это измеренная доля в окне журнала, не оценка.
Заявленные 10 % не подтвердились.

### Цена — размеры, которых на листе нет

У вырезок 16054 значений полей. Сравнение — по значению после нормализации
ГОСТ (`drawing_text.normalize`), чтобы «Ф44Н7» и «⌀44H7» были одним.

| | значений | из них величин |
|---|---|---|
| не нашлось подстрокой в чтении листа | 1992 | 909 |
| …и ни одного заметного слова значения на листе нет | **1043** | **685** |
| …и значение не короче четырёх знаков | — | **468** |

Второй порог нужен потому, что подстрока — тест строгий: лист мог
прочитать то же значение с другими пробелами («P = 16 МПа» против
«P=16 МПа»), и тогда «не нашлось» — промах сравнения, а не промах листа.
Поэтому у каждого значения считается доля его собственных заметных слов
(≥3 знаков), которые на листе всё-таки есть; потерей считается значение,
у которого таких слов нет. У 455 из 468 доля — ровно ноль: на листе нет
ни одного слова из значения.

Третий порог отбрасывает короткие значения («p2», «⌀12», «I», «XT6»),
про которые короткая подстрока ничего не доказывает в обе стороны.

Потерянные величины по категориям (без коротких): `callout` 226,
`size` 190, `roughness` 30, `position` 14, `radius` 3, `tolerance` 3,
`thread` 2.

**Страниц, теряющих хотя бы одну величину, — 226 из 432 (52 %); хотя бы
один размер — 127.**

Чего именно лишается лист:

* размеры: `725*`, `815*`, `1860*`, `L+15`, `⌀27+0,21`, `⌀52+0.3`,
  `0,5×45°`, `1×45°`, `3×45°`, `(190°±3°)*`;
* шероховатости: `Ra 0,5*`, `Ra 1,6`, `Rz 3`, `Ra 0.4`;
* допуски и резьба: `90°±10°`, `M10*`; радиусы: `R1.5`, `R4+1*`;
* обозначения оборудования и клемм: `ККС 101201КУА70С006-Р01`, `XT30`,
  `EL-400PWR`; надписи видов с масштабом: `В(1:2,5)(1:2)`.

Это ровно то, за чем вырезки и добавлялись: фаски, посадочные диаметры,
справочные размеры и шероховатость внутри видов. Вырезка уходит в модель
крупнее, чем тот же вид на листе целиком, и читает то, чего проход по
листу не видит.

### Вердикт лестницы не двигается

`core/ladder/drawing_route.volume` и
`core/ladder/structure.drawing_structure`, посчитанные по страницам
дважды — как есть и без полей вырезок:

| | |
|---|---|
| страниц, где двинулся `structured` | **0** из 432 |
| страниц, где потерян `complete` | 1 |
| страниц, где символов стало меньше | 5 |

То есть `LADDER_DRAWING_OVER_OCR` от обхода вырезок не меняется, и риск,
которого ждали, не подтвердился. Причины две. Символы страницы берутся
максимумом по чтениям листа (`best_drawing[page] = max(...)`), а не суммой,
поэтому текст листа их держит. Состав же решают штамп и обозначение по
ЕСКД, а их несёт только лист целиком: вырезки штампа не видят, и уронить
`structured` они не могут.

## Что это значит для флага

Флаг остаётся выключенным, и включать его в этом виде не стоит: 6.8 %
времени модели не стоят размеров и шероховатостей на половине страниц.
Код и флаг оставлены в ветке — они описывают стык, на котором порядок
вообще можно поменять, и измеримы по той же методике, если чтение листа
целиком когда-нибудь станет читать мелкий текст внутри видов (например,
если лист пойдёт в модель частями с перекрытием). Сам замер повторяется
одной командой:

    python tools/replay_sheet_read_once.py drawfrag.csv.gz --log qwen-lines.gz

## Пределы замера

* Выгрузка — корпус, разобранный при включённых на 14.11 флагах: это
  сегодняшнее поведение прода, а не поведение флага. Замер показывает,
  что флаг выбросил бы из уже прочитанного, и ничего не говорит о том,
  как модель прочитала бы лист иначе.
* Совпадений только короткой подстрокой — 6689. Столько «нашлось» ничего
  не доказывает; поэтому потеря считается по заметным словам, а короткие
  значения вынесены отдельным порогом.
* Время измерено по 256 вырезкам из 1118: остальные лежат вне окна
  журнала. Доля (6.8 %) считана внутри окна и к нему и относится.
